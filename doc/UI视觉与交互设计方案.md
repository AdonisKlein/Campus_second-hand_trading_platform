# 校园二手交易平台 UI 视觉与交互设计方案

> 状态：评审草案 v0.1
> 目标：Web、Windows、Android/iOS 使用同一种品牌感觉，同时适应各自的屏幕和操作方式。

## 1. 设计方向

建议使用“航空蓝 + 活力黄”的组合。

- 航空蓝代表可信、安全、校园和科技感，用于品牌、登录、主要按钮和选中状态。
- 活力黄代表年轻、闲置流转和行动感，用于发布、价格、促销和关键提醒。
- 大面积背景使用偏冷的浅灰蓝，避免整页高饱和颜色造成疲劳。
- 商品图片是首页主角，颜色和装饰不能抢商品内容。

关键词：

- 年轻，但不幼稚。
- 活跃，但不杂乱。
- 可信，但不像银行。
- 校园化，但不直接复制学校官网。

暂用品牌名“航集 Campus Market”制作样板，仅用于展示视觉风格，最终产品名称可以更换。

## 2. 网上参考了什么

| 参考 | 借鉴的部分 | 不复制的部分 |
|---|---|---|
| [闲鱼应用截图](https://app.meizu.com/apps/public/detail?package_name=com.taobao.idlefish) | 图片优先商品流、明显搜索框、黄色行动色、中间发布入口 | 商标、鱼形图标、整页布局、文案和插画 |
| [Material Design 3 交互状态](https://m3.material.io/foundations/interaction/states/overview) | 按钮的悬停、按下、焦点和禁用状态不能只靠一种颜色 | Google 品牌外观 |
| [Fluent 2](https://fluent2.microsoft.design/) 和 [Windows 导航原则](https://learn.microsoft.com/en-us/windows/apps/design/basics/navigation-basics) | Windows 端侧栏、清楚一致的导航、键盘操作和焦点 | Microsoft 产品的完整外观 |
| [Ant Design 设计说明](https://github.com/ant-design/ant-design/blob/master/DESIGN.md) | 管理后台的 4px 间距网格、分层背景、表格和筛选布局 | Ant 默认蓝色主题和组件原样 |

最终设计是这些成熟做法的组合，不是任何一个产品的换皮。

## 3. 颜色方案

### 3.1 主色

| 名称 | 色值 | 用途 |
|---|---|---|
| 航空蓝 600 | #155EEF | 主按钮、链接、选中状态、Logo |
| 航空蓝 700 | #004EEB | 主按钮悬停和按下 |
| 航空蓝 100 | #EAF2FF | 选中背景、信息提示 |
| 活力黄 500 | #FFC83D | 发布按钮、价格点缀、活动标记 |
| 活力黄 100 | #FFF5CC | 温和提示背景 |

黄底按钮使用深色文字 #182230，不使用白字，保证可读性。

### 3.2 中性色

| 名称 | 色值 | 用途 |
|---|---|---|
| 页面背景 | #F6F8FC | 页面最底层 |
| 卡片背景 | #FFFFFF | 商品卡片、表单、弹窗 |
| 主要文字 | #182230 | 标题和正文 |
| 次要文字 | #667085 | 时间、说明、辅助信息 |
| 边框 | #E4E7EC | 输入框、分割线 |
| 禁用背景 | #F2F4F7 | 禁用按钮和占位 |

### 3.3 状态色

| 状态 | 色值 | 示例 |
|---|---|---|
| 成功 | #16A34A | 发布成功、交易完成 |
| 警告 | #F59E0B | 等待确认、即将超时 |
| 错误 | #DC2626 | 删除、违规、支付失败 |
| 信息 | #2563EB | 普通说明和系统消息 |

状态不能只靠颜色表达，必须同时显示图标或文字。

### 3.4 深色模式

- 页面背景：#0D1420。
- 卡片背景：#151F2E。
- 次级卡片：#1D2939。
- 主要文字：#F8FAFC。
- 次要文字：#A7B0C0。
- 边框：#344054。
- 蓝色提高到 #6EA8FE，黄色使用 #FFD666。

首期优先做好浅色模式，深色模式可以在 Web 和客户端框架稳定后加入。

## 4. 字体、圆角和间距

### 4.1 字体

    font-family:
      Inter,
      "PingFang SC",
      "Microsoft YaHei",
      "Noto Sans CJK SC",
      sans-serif

| 类型 | 桌面 | 移动 | 用途 |
|---|---:|---:|---|
| 大标题 | 32px / 40px | 26px / 34px | 页面主标题 |
| 二级标题 | 24px / 32px | 20px / 28px | 区域标题 |
| 卡片标题 | 16px / 24px | 15px / 22px | 商品标题 |
| 正文 | 14px / 22px | 14px / 22px | 普通文字 |
| 辅助文字 | 12px / 18px | 12px / 18px | 时间和标签 |
| 价格 | 22px / 28px | 20px / 26px | 商品价格 |

价格数字使用 700 字重，人民币符号稍小。

### 4.2 间距

统一使用 4px 网格：

    4 / 8 / 12 / 16 / 24 / 32 / 48 / 64

常用规则：

- 按钮内部：上下 10px，左右 16px。
- 卡片内部：16px。
- 移动页面左右边距：16px。
- 桌面内容最大宽度：1280px。
- 桌面卡片间距：20–24px。

### 4.3 圆角和阴影

- 小标签和输入框：8px。
- 按钮和普通卡片：12px。
- 商品图片和大卡片：16px。
- 弹窗和抽屉：20px。
- 发布主按钮：圆形或 999px 胶囊。

卡片默认使用细边框，不到处使用重阴影。只有悬停卡片、弹窗和下拉菜单增加阴影。

## 5. 页面布局

### 5.1 Web 学生端

桌面宽度大于等于 1200px：

    顶部栏 64px
    ┌ Logo ─ 搜索框 ─ 首页/分类/消息 ─ 发布按钮 ─ 头像 ┐
    └─────────────────────────────────────────────┘

    页面宽度最大 1280px
    ┌ 分类和筛选 240px ┬ 商品区域，自适应 3–5 列 ┐
    └─────────────────┴────────────────────────┘

- 顶部搜索框始终容易找到。
- 首页商品卡片以图片为主。
- 商品详情采用左侧图片、右侧价格和操作，向下是描述、卖家和评价。
- 购买/私聊按钮在详情页右侧保持可见。

平板 768–1199px：

- 筛选栏变成顶部按钮，点击后从右侧弹出。
- 商品显示 2–3 列。

### 5.2 移动端

底部固定五个入口：

    首页 | 分类 | 发布 | 消息 | 我的

- 发布按钮位于中间，使用活力黄圆形按钮。
- 首页顶部使用品牌、搜索框和消息入口。
- 商品使用两列图片流。
- 商品详情底部固定“聊一聊”和“立即购买”。
- 重要操作使用底部弹层，不使用屏幕中央的小弹窗。

### 5.3 Windows 端

- 左侧导航栏展开时 220px，收起时 72px。
- 中间为主要内容，右侧可按需打开聊天或订单详情面板。
- 支持 Ctrl+K 聚焦搜索、Ctrl+N 发布商品、Esc 关闭弹层。
- 鼠标悬停、键盘焦点和右键菜单都要有明确状态。
- 普通学生 Windows 端和 Web 保持一致，不做复杂桌面软件外观。

### 5.4 管理员后台

    左侧导航 232px
    ┌ 控制台 / 用户 / 商品 / 订单 / 举报 / 内容 / 日志 ┐
    └──────────────────────────────────────────────┘

    右侧
    顶栏：面包屑、全局搜索、通知、管理员头像
    内容：统计卡片、筛选器、表格、详情抽屉

- 表格信息密度高于学生端。
- 危险操作使用红色文字按钮，并二次确认。
- 查看详情尽量使用右侧抽屉，保留列表筛选条件。
- 每个管理结果显示操作人、时间和原因。

## 6. 核心组件

### 6.1 商品卡片

必须包含：

- 4:3 或 1:1 商品图片。
- 最多两行标题。
- 醒目的价格。
- 商品新旧程度、校区或交易方式标签。
- 卖家头像、昵称和学校认证标记。
- 收藏按钮。

悬停时：

- 卡片上移 2px。
- 边框变为浅蓝。
- 图片轻微放大到 1.02 倍。

不要在卡片中显示过多文字。发布时间、详细地址和完整描述放到详情页。

### 6.2 按钮

- 蓝色主按钮：登录、保存、确认。
- 黄色行动按钮：发布商品、立即购买。
- 白底描边按钮：取消、返回、筛选。
- 红色危险按钮：删除、强制下架。
- 文字按钮：低风险次要操作。

每个按钮都需要默认、悬停、按下、键盘焦点、加载和禁用状态。

### 6.3 标签

- 学校已认证：蓝色浅底。
- 当面交易：绿色浅底。
- 可小刀/可议价：黄色浅底。
- 已预留：橙色浅底。
- 已售出：灰色浅底。
- 管理员下架：红色浅底。

### 6.4 表单

- 标签放在输入框上方，不只使用 placeholder。
- 错误信息显示在输入框下方。
- 验证码输入框旁显示“获取验证码”和倒计时。
- 密码提供显示/隐藏按钮和要求提示。
- 图片上传使用大面积拖拽区，并支持手机相机。

## 7. 关键交互流程

### 7.1 注册和登录

登录页只显示：

- 邮箱。
- 密码。
- 登录按钮。
- 注册、忘记密码入口。

注册使用三步：

1. 输入邮箱并获取验证码。
2. 输入验证码。
3. 设置密码和昵称。

学校认证不放在注册必经流程，先放到个人中心，避免增加新用户流失。

### 7.2 发布商品

移动端分四步：

1. 添加图片。
2. 标题、分类和描述。
3. 价格、新旧程度、校区和交易方式。
4. 预览并发布。

草稿自动保存。退出时不弹出“是否保存”，直接保留草稿并轻提示。

### 7.3 浏览到下单

    首页/搜索
      -> 商品详情
      -> 私聊或立即购买
      -> 确认价格和交付方式
      -> 创建预留
      -> 成功页和订单详情

商品被别人抢先预留时，原页面保留并给出友好提示，不跳到空白错误页。

### 7.4 私聊和议价

- 普通文字消息使用聊天气泡。
- 议价使用结构化报价卡片，显示原价、报价和接受/拒绝。
- 商品摘要固定在会话顶部。
- 订单创建后，会话顶部切换为订单状态卡片。
- 举报和屏蔽放在右上角更多菜单中。

### 7.5 订单

订单详情使用时间线：

    已创建 -> 卖家确认 -> 等待交付 -> 买家确认 -> 已完成

当前步骤用蓝色，等待步骤用灰色，异常用红/橙色并显示文字原因。

## 8. 动效和反馈

- 按钮按下：80–120ms。
- 卡片悬停：150ms。
- 抽屉和底部弹层：220–280ms。
- 页面主要切换：不超过 350ms。
- 收藏可以先乐观更新，失败后恢复并提示。
- 提交订单、发布商品等重要操作必须显示加载状态并禁止重复点击。
- 加载列表使用骨架屏，不用一直旋转的圆圈。
- 成功提示 2–3 秒自动消失；错误提示保留到用户处理或关闭。
- 尊重系统“减少动态效果”设置。

## 9. 图片和图标风格

- 商品图使用真实、干净、自然光照片。
- 首页卡片图片比例尽量统一，原图使用居中裁切。
- 空状态插画采用简单线条和低饱和蓝黄配色。
- 图标统一使用一套圆角线性图标，默认 20px，导航 24px。
- 不混用 Emoji、实心图标、线性图标和多个图标库。
- Logo 可以使用“纸飞机/循环箭头/商品标签”的组合，但不要直接使用北航校徽或闲鱼鱼形标志。

## 10. 可用性要求

- 正文与背景对比度至少 4.5:1。
- 移动端可点击区域不小于 44×44px。
- 键盘 Tab 顺序与视觉顺序一致。
- 所有输入框、按钮和卡片有清楚焦点框。
- 图片有替代文字。
- 状态不能只靠红、绿区分。
- 支持浏览器放大到 200%。
- 重要流程不依赖滑动手势才能完成。

## 11. 推荐的第一批页面

学生端：

1. 首页。
2. 分类/搜索结果。
3. 商品详情。
4. 邮箱登录、注册和找回密码。
5. 发布商品。
6. 消息列表和聊天详情。
7. 我的收藏、发布和资料。
8. 我买到的、我卖出的和订单详情。

管理员端：

1. 控制台。
2. 用户列表。
3. 商品列表和详情抽屉。
4. 订单列表和详情。
5. 举报处理。
6. 内容和分类设置。
7. 管理日志。

## 12. 验收方式

视觉稿通过以下条件才进入开发：

- 一眼能区分主要操作、次要操作和危险操作。
- 首页 3 秒内能找到搜索、发布和消息。
- 不看颜色也能看懂商品和订单状态。
- 手机单手能完成发布、聊天和下单。
- Windows 端可用键盘完成搜索和主要导航。
- 管理员从列表打开详情后，返回时筛选条件不丢失。
- 浅色模式关键文字达到对比度要求。
