# 校园二手交易平台测试文档

**版本**：V1.0  
**日期**：2026-08-29  
**测试对象**：校园二手交易平台 Web 端、Spring Boot 后端及 MySQL 数据层

本文是本项目的正式测试报告；《测试清单》用于逐项执行和回归勾选，《全量测试文档》用于环境搭建和命令操作，三者不重复记录测试结论。

## 1. 测试目标

验证游客、学生用户和管理员在账号认证、校园搜索、商品发布与维护、公开留言、私聊、交易、订单工作台、举报治理等场景下的功能正确性、权限安全性、数据一致性和响应式可用性。本文参考示例文档的“编号、输入、前置条件、预期结果、实际证据”格式编写，业务术语以 `CONTEXT.md` 为准。

## 2. 测试环境

| 项目 | 配置 |
| --- | --- |
| 后端 | JDK 25、Spring Boot 3.5、JUnit 5、Mockito、MockMvc |
| 数据库 | MySQL 8.4；Testcontainers；Flyway；Hibernate validate |
| 快速测试 | H2、固定 `Clock`、测试数据工厂 |
| 前端 | HTML/CSS/JavaScript、Node.js `node:test`、`node --check` |
| 端到端 | Docker Compose、Nginx、Mailpit、Playwright |

## 3. 测试编号规则

`UNIT-xxx` 表示单元测试，`API-xxx` 表示 API/系统测试，`MYSQL-xxx` 表示 MySQL 迁移或并发测试，`WEB-xxx` 表示前端契约测试，`E2E-xxx` 表示端到端测试，`NF-xxx` 表示非功能测试。编号末位 0 表示主成功路径，1-9 表示异常、权限或边界路径。

## 9. 执行命令

```powershell
cd backend
mvn verify
cd ..\frontend
node --test tests/*.test.js
Get-ChildItem assets/js -Filter *.js | ForEach-Object { node --check $_.FullName }
cd ..
e2e\node_modules\.bin\playwright test --config=e2e/playwright.config.cjs
git diff --check
```

Docker 可用时，`mvn verify` 必须包含真实 MySQL 8.4 Testcontainers。Compose E2E 使用 Mailpit 查看验证码邮件。测试失败应保留 HTML/JUnit、截图、trace、视频、控制台日志和失败网络请求。

## 10. 通过标准与遗留项

业务规则必须有后端结果断言，权限测试必须包含反向用例；Maven、前端契约、JavaScript 语法和 `git diff --check` 通过；Docker 可用时 MySQL 迁移/并发和 Compose E2E 通过；桌面端与 390px 移动端无整体横向溢出；独立审查无未处理 P0/P1。
