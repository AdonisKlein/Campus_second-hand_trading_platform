# 校园二手交易平台软件概要设计说明书

## 1. 概述

本文档描述校园二手交易平台的总体设计方案，包括系统架构、技术选型、模块划分、接口概览、数据库概要设计、安全设计和部署结构。详细的类、方法和流程设计见《软件详细设计说明书》。

## 2. 总体架构

系统采用简易前后端分离架构：

```text
浏览器
  |
  | HTML/CSS/JavaScript
  v
frontend 静态页面
  |
  | HTTP JSON
  v
Spring Boot REST API /api
  |
  | Spring Data JPA
  v
MySQL campus_secondhand
```

前端负责页面展示、表单交互、本地登录态保存和 REST API 调用。后端负责业务校验、数据持久化、统一响应、邮件验证码和管理权限校验。数据库负责保存用户、商品、留言、订单和验证码数据。

## 3. 技术选型

| 层次 | 技术 | 说明 |
|---|---|---|
| 前端 | HTML、CSS、JavaScript | 无构建步骤，适合课程项目快速部署。 |
| 后端 | Java 25 LTS、Spring Boot 3.5.14 | 提供 REST API。 |
| 数据访问 | Spring Data JPA | 简化实体持久化和查询。 |
| 数据库 | MySQL 8.x | 保存业务数据。 |
| 密码安全 | Spring Security Crypto BCrypt | 保存密码散列。 |
| 邮件 | Spring Boot Mail | 发送邮箱验证码。 |
| 测试 | JUnit 5、MockMvc、H2 | 后端自动化测试。 |
| 构建 | Maven | 依赖管理和测试运行。 |

## 5. 模块划分

### 5.1 用户模块

负责注册、登录、邮箱验证码、忘记密码、资料查询和资料修改。用户模块维护账号状态、登录失败次数和临时锁定时间。

### 5.2 商品模块

负责商品发布、商品列表、关键词搜索、分类筛选和商品详情。商品状态包括 `ON_SALE`、`SOLD`、`REMOVED`。

### 5.3 留言模块

负责商品详情页留言列表、发送留言、修改自己的留言和删除自己的留言。管理员删除留言由管理员模块提供。

### 5.4 订单模块

负责订单创建、用户相关订单查询和订单状态更新。订单创建成功后联动修改商品状态为 `SOLD`。

### 5.5 管理员模块

负责普通用户状态管理、全量留言管理和商品上下架管理。所有管理员接口都校验 `adminId` 对应用户是否为 `ADMIN`。

### 5.6 公共模块

提供统一响应结构、跨域配置、邮件发送服务和全局异常处理。

## 6. 数据库概要设计

| 表名 | 主要字段 | 说明 |
|---|---|---|
| `users` | `username`、`password_hash`、`email`、`role`、`status`、`locked_until` | 用户账号和状态。 |
| `items` | `title`、`category`、`price`、`image_url`、`seller_id`、`status` | 商品信息。 |
| `messages` | `item_id`、`sender_id`、`receiver_id`、`content` | 商品留言。 |
| `trade_orders` | `item_id`、`buyer_id`、`seller_id`、`status` | 交易订单。 |
| `email_verification` | `email`、`code`、`expires_at`、`attempts`、`used` | 邮箱验证码。 |

主要关系：

- 一个用户可发布多个商品。
- 一个商品可拥有多条留言。
- 一个订单关联一个商品、一个买家和一个卖家。
- 验证码按邮箱保存，用于注册、修改邮箱和重置密码。

## 7. 接口概要设计

接口统一挂载在 `/api` 下，统一返回：

```json
{
  "success": true,
  "message": "success",
  "data": {}
}
```

| 模块 | 接口类型 | 说明 |
|---|---|---|
| 用户 | `/users/**` | 注册、登录、验证码、忘记密码、资料管理。 |
| 商品 | `/items/**` | 商品列表、详情、发布。 |
| 留言 | `/messages/**` | 商品留言查询、发送、修改、删除。 |
| 订单 | `/orders/**` | 订单创建、查询、状态更新。 |
| 管理员 | `/admin/**` | 用户、留言、商品管理。 |

```javascript
const API_BASE = "http://localhost:8080/api";
```

## 9. 安全概要设计

- 密码使用 BCrypt 散列保存。
- 注册、修改邮箱、忘记密码使用邮箱验证码。
- 登录失败达到 3 次后锁定 10 分钟。
- 管理员接口校验 `role = ADMIN`。
- 被禁用用户不能登录、发布商品、发送留言或创建订单。
- 前端只保存用户基本信息，不保存密码。

## 10. 部署概要

- MySQL 执行 `database/schema.sql` 和 `database/seed.sql`。
- 后端修改 `backend/src/main/resources/application.yml` 中数据库和邮件配置。
- 后端在 `backend/` 下执行 `mvn spring-boot:run`。
- 前端可直接打开 HTML，也可在 `frontend/` 下执行 `python -m http.server 5500`。

## 11. 设计限制

- 已实现受控 JPG/PNG 商品图片上传，当前单机使用持久卷保存。
- Web 使用 Spring Security + JDBC Session；Windows/移动端 Token adapter 尚未实现。
- 未实现支付、物流和评价；文本私聊采用短轮询，WebSocket/SSE 尚未实现。
- 订单动作已经按买卖双方和状态机细分权限。
