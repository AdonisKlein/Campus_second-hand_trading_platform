### 1. 准备环境

在项目根目录执行：

```
docker version
docker compose version
java -version
mvn -version
node -v
npm -v
```

确认 `deploy/.env` 已存在。若没有：

```
Copy-Item deploy/.env.example deploy/.env
```

然后填写数据库密码和 `VERIFICATION_PEPPER`。

### 2. 启动完整环境

启动 MySQL、Backend、Web 和 Mailpit：

```
docker compose --env-file deploy/.env `
  -f deploy/docker-compose.yml `
  -f deploy/docker-compose.mailpit.yml `
  up -d --build
```

检查容器状态：

```
docker compose --env-file deploy/.env `
  -f deploy/docker-compose.yml `
  -f deploy/docker-compose.mailpit.yml ps
```

确认 Backend 健康：

```
Invoke-RestMethod http://localhost:8088/api/actuator/health/liveness
```

应返回：

```
status : UP
```

### 3. 执行后端全量测试

```
cd backend
mvn clean verify
cd ..
```

该命令会执行：

- JUnit 单元测试
- MockMvc/API 集成测试
- MySQL 8.4 Testcontainers 测试
- Flyway 空库迁移校验
- Hibernate Schema 校验
- 并发测试

报告位置：

```
backend/target/surefire-reports/
backend/target/failsafe-reports/
backend/target/reports/
```

### 4. 执行前端测试

```
node --test frontend/tests/*.test.js
```

执行全部 JavaScript 语法检查：

```
Get-ChildItem frontend/assets/js -Filter *.js |
  ForEach-Object { node --check $_.FullName }
```

可以用下面命令确认退出状态：

```
$LASTEXITCODE
```

如果结果是 `0`，说明检查成功。也可以显示检查了多少个文件：

```
$files = Get-ChildItem frontend/assets/js -Filter *.js
$files | ForEach-Object { node --check $_.FullName }
"Checked $($files.Count) JavaScript files"
```

### 5. 执行 Playwright 全量 E2E

```
cd e2e
npm ci
npm run test:e2e:compose
```

报告位置：

```
e2e/test-results/playwright-report/
e2e/test-results/junit.xml
e2e/test-results/artifacts/
```

查看 HTML 报告：

```
npx playwright show-report test-results/playwright-report
```

### 6. 手工验收

浏览器打开：

```
http://localhost:8088
```

Mailpit 邮件查看：

```
http://localhost:8025
```

至少手工验证：

- 注册、登录、退出
- 商品搜索、发布、编辑、下架
- 商品留言和私聊
- 购买意向、订单状态流转
- 举报提交和管理员处理
- 普通学生访问管理员页面返回 403
- 个人资料修改
- 验证码邮件能够在 Mailpit 中收到

### 7. 停止测试环境

测试完成后执行：

```
docker compose --env-file deploy/.env `
  -f deploy/docker-compose.yml `
  -f deploy/docker-compose.mailpit.yml `
  down
```
