# 校园二手交易平台软件用户手册

## 1. 访问平台

推荐使用 Docker 部署后访问：

```text
http://localhost/
```

本机前后端分开调试时访问：

```text
http://localhost:5500/
```

不要直接双击 HTML 或使用 `file://`。登录 Cookie、CSRF 和跨域请求需要通过 HTTP 工作。完整启动方式见《软件部署文档》。

平台主要页面包括搜索首页、商品详情、发布、我的发布、订单工作台、私聊消息、个人中心、我的举报和管理中心。管理中心只对管理员显示。

## 2. 浏览与搜索（UC02）

打开首页后会显示最新的在售商品。可以输入一个或多个关键词搜索；提交搜索后可：

- 切换“商品”或“用户”结果。
- 按相关度、最新、活跃、同区域优先、信用或价格排序。
- 按价格、校园区域、商品标签和卖家筛选商品。

商品结果只展示仍在售、允许公开且卖家状态为 `ACTIVE` 的商品。用户搜索只显示公开昵称、校园区域、信用和活跃信息，不显示邮箱或手机号。

点击商品进入详情页，可以查看图片、价格、状态、描述、安全卖家摘要、同卖家其他商品和公开问答。页面显示的按钮会随登录身份、商品状态和本人购买意向变化。

## 3. 注册、登录与找回密码（UC01）

### 注册

1. 打开注册页，填写邮箱并发送注册验证码。
2. 在邮件中查看验证码。本地 Mailpit 环境可访问 `http://localhost:8025`。
3. 填写用户名、昵称和密码后提交。密码为 6～12 位，必须同时包含字母和数字。
4. 注册成功后系统建立登录状态并进入个人中心。

验证码有用途、有效期、尝试次数和发送频率限制。注册验证码不能用于重置密码。

### 登录与退出

在个人中心使用邮箱和密码登录。连续输错密码会触发临时锁定；被管理员禁用的账号不能登录。

登录状态保存在服务端 Session 中。不要尝试修改浏览器本地数据冒充其他用户。退出后当前会话立即失效。

### 找回密码

1. 在个人中心切换到找回密码。
2. 输入已注册邮箱并申请重置验证码。
3. 输入验证码和新密码。
4. 重置成功后使用新密码登录；旧密码和旧认证状态失效。

## 4. 维护个人资料（UC01）

登录后在个人中心修改昵称、手机号和校园区域。校园区域用于公开资料展示和“同区域优先”排序；它不是实时定位或精确地址。

邮箱属于登录资料，不会出现在公开用户搜索或商品详情中。

## 5. 发布和维护商品（UC03）

### 发布商品

1. 点击“发布”，填写标题、价格、描述和校园区域。
2. 选择最多 4 个商品标签，例如“可小刀”“仅自提”“支持验货”。
3. 选择一张 JPG 或 PNG 图片，文件不得超过 5MB。
4. 等待图片预览和上传完成后提交商品。

平台会检查图片格式、尺寸和归属，重新编码图片以移除照片元数据。发布成功后商品进入在售且公开状态。

### 我的发布

在“我的发布”中可以查看全部本人商品、编辑允许字段、卖家下架或重新上架。

- 预留中或已售出的商品不能编辑。
- 卖家下架的商品可以按规则重新上架。
- 管理员移除的商品不能由卖家自行恢复。
- 商品交易状态和管理员审核状态是两套独立状态。

## 6. 公开问答与私聊（UC04）

### 公开问答

商品详情下方的问答对所有能够查看商品的访客公开。登录学生可以发布留言，只能修改或删除自己的留言。不要在公开问答中填写手机号、验证码、密码或其他敏感信息。

### 私聊卖家

登录后可从商品详情发起私聊，也可以从本人订单继续联系交易对方。同一商品与同一买卖双方只建立一个会话。

消息页支持：

- 查看会话列表和未读数。
- 按时间向前加载历史消息。
- 发送失败后重试。
- 标记消息已读。
- 举报或屏蔽对方。

屏蔽后双方都不能继续发送，但仍可查看历史；解除自己的屏蔽后可按规则恢复沟通。私聊仅双方可见，管理员不能直接查看聊天正文。

## 7. 购买意向和当面交易（UC05～UC06）

### 提交购买意向

在他人的在售商品详情点击“我想要”，确认后形成购买意向。购买意向不是锁单：商品仍继续在售，其他买家也可以提交意向。

不能购买自己的商品，也不能对同一商品重复提交有效意向。

### 卖家选择买家

卖家在订单工作台的“我卖出的”视角查看同一商品的多条意向，可以比较买家公开信用并接受或拒绝。

卖家接受一位买家后：

- 该订单进入“待当面交易”。
- 商品进入预留状态。
- 其他尚未回应的意向关闭。

### 完成、取消和超时

当面核验并交接商品后，由买家确认完成，此时商品才真正售出。若交易取消或预留超时，订单关闭并按规则释放商品，使其恢复在售。

建议在校内公共场所验货，不要提前转账，不要在私聊中发送验证码或密码。

### 订单工作台

订单页可以切换“我买到的 / 我卖出的”和交易阶段，查看：

- 阶段数量与待办。
- 卖家按商品分组的购买意向。
- 交易时间线、剩余时间和关闭原因。
- 当前允许执行的操作。
- 商品详情、与对方私聊和举报入口。

页面只显示本人参与的交易。

## 8. 举报与处理结果（UC07）

登录学生可以举报商品、公开留言或其他学生用户。选择举报对象、原因并填写必要说明后提交。

限制如下：

- 不能举报自己。
- 不能对同一对象重复举报。
- 每 24 小时最多提交 20 条举报。

在“我的举报”中可以查看处理中、成立或驳回结果以及管理员说明。提交举报不代表对象已经违规，最终结果以管理员核查为准。

## 9. 管理中心（UC08）

管理员登录后可以：

- 查看举报队列，核查快照并决定成立或驳回。
- 对成立举报执行下架商品、移除留言或禁用用户等匹配措施。
- 查看和管理用户、商品及公开留言。
- 填写处理说明并保留审计记录。

普通学生不能进入管理中心或调用管理员接口。管理员无权通过管理中心读取学生私聊正文。

## 10. 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 页面显示未登录 | 确认使用文档规定的 HTTP 地址，清理旧 Cookie 后重新登录。 |
| 写操作返回 403 | 刷新页面重新获取 Session/CSRF；不要从 `file://` 打开页面。 |
| 验证码未收到 | 检查邮箱地址和发送频率；本地环境查看 Mailpit，生产环境联系管理员检查 SMTP。 |
| 图片上传失败 | 确认是 JPG/PNG、不超过 5MB，尺寸和本人配额符合要求。 |
| 无法提交购买意向 | 检查是否登录、商品是否仍在售、是否为本人商品或已有有效意向。 |
| 无法重新上架 | 商品可能已售出、处于预留，或已被管理员移除。 |
| 无法发送私聊 | 检查网络、会话参与者资格以及双方是否存在屏蔽。 |
| 订单操作已变化 | 其他参与者或超时任务可能已更新状态，刷新订单工作台查看最新允许动作。 |
