# 校园二手交易平台软件用户手册

## 1. 系统入口

可直接打开：

```text
frontend/index.html
```

也可通过静态服务器访问：

```text
http://localhost:5500/index.html
```

页面导航包括：首页、注册、发布物品、订单管理、个人中心、管理中心。

## 2. 浏览和搜索商品

打开首页后，系统自动展示当前可售商品。商品卡片包含图片、分类、标题、价格和描述。

搜索步骤：

1. 在关键词输入框输入商品关键字。
2. 选择商品分类，或保持全部分类。
3. 点击搜索。
4. 点击商品卡片进入详情页。

## 3. 注册账号

进入注册页：

```text
frontend/register.html
```

操作步骤：

1. 输入用户名。
2. 输入 6 到 12 位字母和数字组合的密码。
3. 输入昵称。
4. 输入邮箱。
5. 点击发送验证码。
6. 从邮箱获取验证码。
7. 输入验证码并提交注册。

注册成功后页面会自动跳转到登录表单，并显示一次性成功提示；随后使用刚注册的邮箱和密码登录。

注意：用户名不能重复，验证码错误或过期会导致注册失败。

## 4. 登录账号

进入个人中心：

```text
frontend/profile.html
```

操作步骤：

1. 输入注册邮箱。
2. 输入密码。
3. 点击登录。

登录成功后由服务器保存登录状态。刷新页面仍可使用，退出登录或账号被禁用后会话立即失效。

登录规则：

- 连续 3 次输错密码后账号锁定 10 分钟。
- 被管理员禁用的账号不能登录。
- 退出登录后需要重新登录才能进行需要身份的操作。

## 5. 忘记密码

在个人中心点击忘记密码。

操作步骤：

1. 输入已注册邮箱。
2. 点击发送验证码。
3. 输入收到的验证码。
4. 输入新密码。
5. 提交重置。
6. 重置成功后页面会自动跳转到登录表单，并显示一次性成功提示。
7. 使用新密码重新登录。

## 6. 修改个人资料

登录后进入个人中心。

可修改：

- 昵称。
- 手机号。
- 邮箱。

修改邮箱时需要发送并输入新邮箱验证码。

## 7. 发布商品

进入发布页：

```text
frontend/publish.html
```

操作步骤：

1. 确认已经登录。
2. 输入商品标题。
3. 选择分类并输入价格。
4. 从本地选择 JPG 或 PNG 商品图片，等待平台完成安全处理和预览。
5. 填写校园区域、商品标签和描述。
6. 点击发布。

说明：平台会限制图片体积和尺寸并清除照片定位等元数据；不能填写外部图片地址。

## 8. 查看商品详情

在首页点击商品卡片进入详情页。详情页按“判断商品—了解卖家—沟通—表达购买意向”组织，展示商品状态、价格、交易标签、校园区域、详细描述、卖家公开信用摘要、同卖家在售商品和校园交易提醒。

桌面端在图片区右侧集中显示交易决策；移动端图片优先，并在底部固定显示“私聊卖家 / 我想要”。商品不可交易或已经提交意向时，操作区会显示对应状态，不会继续提供无效按钮。

## 9. 公开问答

查看公开问答不需要登录，发布问题需要登录。公开问答适合询问尺寸、配件和使用情况；议价、瑕疵照片、联系方式和见面地点应使用私聊。

发送留言：

1. 登录账号。
2. 进入商品详情页。
3. 输入留言内容。
4. 点击发送。

修改或删除留言：

1. 找到自己发送的留言。
2. 点击编辑或删除。
3. 编辑后保存，或确认删除。

## 9.1 私聊卖家

公开留言适合询问所有买家都能看到的商品信息；私聊仅买卖双方可见。

1. 登录学生账号并进入在售商品详情。
2. 点击“私聊卖家”，系统会创建或打开已有会话。
3. 在“消息”页发送文本；红色角标表示未读消息，页面会自动刷新。
4. 可加载更早消息，也可举报或屏蔽对方。任一方屏蔽后暂时不能继续发送，历史仍保留。

请勿提前转账，建议在校内公共场所当面验货。管理员不会通过私聊索要密码或验证码。

## 10. 提交购买意向

登录后在商品详情页点击“我想要 · 提交购买意向”。

创建规则：

- 不能购买自己发布的商品。
- 已售出、已预留或已下架商品不能新建意向。
- 提交意向后商品继续公开在售，不会立即为你锁定；请在私聊中与卖家确认细节。
- 卖家选择你以后，商品才进入预留并等待当面交接。

## 11. 管理订单

进入订单管理页：

```text
frontend/orders.html
```

页面先切换“我买到的 / 我卖出的”，再按“待回应 / 待当面交易 / 已结束”筛选：

- 卖家视角把同一商品的购买意向放在一起，可比较买家的公开信用、校园区域和提交时间，再选定或拒绝。
- 买家视角显示提交意向、卖家选择、当面交易和确认取货时间线；未被选择、取消或超时会显示具体原因。
- 需要处理的记录优先显示并展示剩余时间；过期动作不会继续显示。
- “查看进度”打开订单详情；“私聊对方”会打开对应商品会话，即使商品已经被预留也能继续沟通。
- 取消、拒绝、确认取货等操作使用页面内确认框，确认前不会改变数据。

## 12. 管理中心

管理员登录后进入：

```text
frontend/admin.html
```

默认管理员：

```text
用户名：admin
密码：abc123
```

管理功能：

- 用户管理：禁用或恢复普通用户。
- 留言管理：查看全部留言并删除不合规留言。
- 商品管理：下架或恢复商品。

普通用户无管理员权限，不能执行管理操作。

## 13. 常见提示

| 提示 | 含义 |
|---|---|
| 请先登录 | 当前操作需要登录。 |
| 验证码错误或已过期 | 验证码不正确或超过有效期。 |
| 账号已被临时锁定 | 连续输错密码达到 3 次，需要等待 10 分钟。 |
| 账号已被管理员禁用 | 管理员禁用了该账号。 |
| 物品已被下单或售出 | 商品不能重复下单。 |
| 无管理员权限 | 当前用户不是管理员。 |
