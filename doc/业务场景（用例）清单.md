## UC01 学生注册并完成邮箱验证

- **需求编号**：REQ01  
- **参与者**：学生用户、邮件验证码服务  
- **触发条件**：学生希望创建平台账号。  
- **前置条件**：学生拥有可接收验证码的邮箱；邮箱未被注册。  
- 主成功流程：  
  1. 学生提交注册邮箱。  
  2. 系统生成注册用途验证码并发送。  
  3. 学生提交验证码、密码和必要资料。  
  4. 系统校验验证码用途、有效期和次数。  
  5. 系统创建 `ACTIVE` 学生账号并建立登录状态。
- **备选/异常流程**：邮箱已存在、验证码错误/过期、密码不符合规则、验证码频率超限。  
- **可验证结果**：注册成功后可登录；错误输入不会创建账号。  
- **追溯关系**：`REQ01 / UC01 / SYS-SEQ01 / COMP-ACCOUNT01 / OBJ-ACCOUNT01 / UNIT-TC01 / INT-TC01 / E2E-TC01`

## UC02 学生登录、退出与会话恢复

- **需求编号**：REQ02  
- **参与者**：学生用户、管理员、Session 服务  
- **触发条件**：用户提交登录或退出请求。  
- **前置条件**：账号已注册；登录时账号状态为可用。  
- **主成功流程**：用户提交邮箱和密码，系统验证后创建 HttpOnly Session；访问页面时通过 `/users/me` 恢复身份；退出时销毁会话。  
- **备选/异常流程**：密码错误、账号被禁用、认证版本失效、旧请求返回覆盖新会话。  
- **可验证结果**：只有当前 Session 能代表用户；退出或禁用后旧会话不能继续操作。  
- **追溯关系**：`REQ02 / UC02 / SYS-SEQ02 / COMP-SESSION01 / OBJ-SESSION01 / UNIT-TC02 / INT-TC02 / E2E-TC02`

## UC03 学生找回并重置密码

- **需求编号**：REQ03  
- **参与者**：学生用户、邮件验证码服务  
- **触发条件**：学生无法使用原密码登录。  
- **前置条件**：邮箱已注册。  
- **主成功流程**：申请重置验证码，提交有效验证码和新密码，系统更新密码并撤销旧认证状态。  
- **备选/异常流程**：邮箱不存在、验证码用途不匹配、过期、重复使用或超限。  
- **可验证结果**：新密码可登录，旧密码失效。  
- **追溯关系**：`REQ03 / UC03 / SYS-SEQ03 / COMP-ACCOUNT02 / OBJ-PASSWORD01 / UNIT-TC03 / INT-TC03 / E2E-TC03`

## UC04 学生维护个人资料和校园区域

- **需求编号**：REQ04  
- **参与者**：学生用户  
- **触发条件**：学生修改昵称、校园区域等资料。  
- **前置条件**：已登录。  
- **主成功流程**：读取本人资料，提交合法修改，系统保存并返回更新后的公开资料。  
- **备选/异常流程**：未登录、字段非法、尝试修改账号安全字段或他人资料。  
- **可验证结果**：个人中心和后续搜索中的公开信息更新，邮箱等隐私字段不外泄。  
- **追溯关系**：`REQ04 / UC04 / SYS-SEQ04 / COMP-PROFILE01 / OBJ-USER01 / UNIT-TC04 / INT-TC04 / E2E-TC04`

## UC05 搜索并筛选校园商品/用户

- **需求编号**：REQ05  
- **参与者**：游客、学生用户  
- **触发条件**：输入一个或多个搜索关键词并提交搜索。  
- **前置条件**：无；“离我最近”排序需要登录用户校园区域。  
- **主成功流程**：系统按最多 8 个关键词取交集，选择商品或用户范围，应用价格、区域、标签和排序条件，返回分页结果。  
- **备选/异常流程**：关键词为空、关键词超过上限、无匹配结果、游客使用需登录的区域排序。  
- **可验证结果**：商品只返回在售、可见且卖家有效的记录；用户结果不包含邮箱、手机号等隐私字段。  
- **追溯关系**：`REQ05 / UC05 / SYS-SEQ05 / COMP-SEARCH01 / OBJ-SEARCH01 / UNIT-TC05 / INT-TC05 / E2E-TC05`

## UC06 学生发布带图片的二手商品

- **需求编号**：REQ06  
- **参与者**：学生用户、图片存储服务  
- **触发条件**：学生提交商品发布表单。  
- **前置条件**：已登录；图片属于本人上传且通过验证。  
- **主成功流程**：上传并标准化图片，填写标题、描述、价格、区域和标签，系统创建商品并置为 `ON_SALE + VISIBLE`。  
- **备选/异常流程**：图片格式、大小、像素、配额或内容校验失败；字段非法；CSRF 缺失。  
- **可验证结果**：商品可在公开搜索和详情中展示；图片不含 EXIF，路径不可被任意伪造。  
- **追溯关系**：`REQ06 / UC06 / SYS-SEQ06 / COMP-ITEM-PUBLISH01 / OBJ-ITEM01 / UNIT-TC06 / INT-TC06 / E2E-TC06`

## UC07 学生维护自己的商品并下架/重新上架

- **需求编号**：REQ07  
- **参与者**：学生用户  
- **触发条件**：卖家进入“我的发布”并编辑或执行状态操作。  
- **前置条件**：已登录且为商品发布者。  
- **主成功流程**：查看本人商品，修改允许字段，执行卖家下架或重新上架。  
- **备选/异常流程**：非发布者、商品已预留/售出、商品被管理员移除、并发状态冲突。  
- **可验证结果**：只有发布者能操作；管理员移除不能被卖家绕过；交易状态不被错误改变。  
- **追溯关系**：`REQ07 / UC07 / SYS-SEQ07 / COMP-INVENTORY01 / OBJ-ITEM02 / UNIT-TC07 / INT-TC07 / E2E-TC07`

## UC08 查看商品详情并获取交易动作

- **需求编号**：REQ08  
- **参与者**：游客、学生用户  
- **触发条件**：访问商品详情。  
- **前置条件**：商品存在；可见性取决于商品审核状态、交易状态和卖家状态。  
- **主成功流程**：系统一次返回商品资料、卖家安全摘要、购买意向、可执行动作、同卖家在售商品和公开问答。  
- **备选/异常流程**：商品不存在、游客访问不可见商品、卖家本人查看被下架商品、买家已有有效意向。  
- **可验证结果**：不同身份看到不同动作；不暴露邮箱、手机号等敏感字段。  
- **追溯关系**：`REQ08 / UC08 / SYS-SEQ08 / COMP-DETAIL01 / OBJ-ITEM03 / UNIT-TC08 / INT-TC08 / E2E-TC08`

## UC09 参与商品公开问答

- **需求编号**：REQ09  
- **参与者**：游客、学生用户  
- **触发条件**：用户在商品详情发布或维护公开留言。  
- **前置条件**：商品对当前用户可见；修改或删除时留言属于本人。

- **可验证结果**：留言对所有可见访客公开；私聊正文不出现在公开问答中。  
- **追溯关系**：`REQ09 / UC09 / SYS-SEQ09 / COMP-MESSAGE01 / OBJ-MESSAGE01 / UNIT-TC09 / INT-TC09 / E2E-TC09`

## UC10 买卖双方建立私聊并完成消息沟通

- **需求编号**：REQ10  
- **参与者**：买家、卖家  
- **触发条件**：从商品详情或订单工作台发起私聊。  
- **前置条件**：发起者是合法买家或卖家；商品详情新会话要求商品在售且可见。  
- **主成功流程**：创建或复用唯一会话，双方分页查看历史、发送消息、标记已读。  
- **备选/异常流程**：陌生用户访问、屏蔽状态下发送、商品已下架/售出但尝试新建会话、消息频率超限。  
- **可验证结果**：消息仅双方可见；未读数正确；屏蔽后不能发送但历史仍可读。  
- **追溯关系**：`REQ10 / UC10 / SYS-SEQ10 / COMP-CHAT01 / OBJ-CHAT01 / UNIT-TC10 / INT-TC10 / E2E-TC10`

## UC11 买家提交购买意向

- **需求编号**：REQ11  
- **参与者**：学生用户（交易内买家）  
- **触发条件**：买家在商品详情点击“我想要”。  
- **前置条件**：已登录；商品为 `ON_SALE + VISIBLE`；买家不是卖家本人。  
- **主成功流程**：系统从 Session 推导买家身份，创建 `PURCHASE_REQUESTED` 意向，商品继续在售。  
- **备选/异常流程**：重复有效意向、商品状态已变化、卖家本人下单、未登录或 CSRF 失败。  
- **可验证结果**：意向成功创建且不产生独占预留。  
- **追溯关系**：`REQ11 / UC11 / SYS-SEQ11 / COMP-TRADING01 / OBJ-ORDER01 / UNIT-TC11 / INT-TC11 / E2E-TC11`

## UC12 卖家处理购买意向并形成预留订单

- **需求编号**：REQ12  
- **参与者**：学生用户（交易内卖家）  
- **触发条件**：卖家在订单工作台接受或拒绝意向。  
- **前置条件**：已登录且为商品卖家；意向处于可处理状态。  
- **主成功流程**：卖家接受一条意向，商品变为 `RESERVED`，订单进入 `WAITING_HANDOVER`，其他待回应意向关闭。  
- **备选/异常流程**：卖家单独拒绝、意向已过期、商品已被其他并发请求预留、非卖家越权操作。  
- **可验证结果**：同一商品最多一个有效预留；所有状态变化经过 `TradingService`。  
- **追溯关系**：`REQ12 / UC12 / SYS-SEQ12 / COMP-TRADING02 / OBJ-ORDER02 / UNIT-TC12 / INT-TC12 / E2E-TC12`

## UC13 买卖双方完成当面交接交易

- **需求编号**：REQ13  
- **参与者**：买家、卖家、交易超时任务  
- **触发条件**：双方完成线下交接，或订单达到取消/超时条件。  
- **前置条件**：订单处于 `WAITING_HANDOVER`。  
- **主成功流程**：买家确认收到商品，订单变为 `COMPLETED`，商品变为 `SOLD`。  
- **备选/异常流程**：买家或卖家取消、预留超时、非法参与者操作、重复完成。  
- **可验证结果**：完成交易后商品不可重新上架；取消或超时则订单关闭、商品恢复在售。  
- **追溯关系**：`REQ13 / UC13 / SYS-SEQ13 / COMP-TRADING03 / OBJ-ORDER03 / UNIT-TC13 / INT-TC13 / E2E-TC13`

## UC14 学生查看和处理交易工作台

- **需求编号**：REQ14  
- **参与者**：学生用户  
- **触发条件**：进入订单工作台。  
- **前置条件**：已登录。  
- **主成功流程**：选择“我买到的/我卖出的”和交易阶段，查看统计、商品分组、对方公开资料、时间线、剩余时间和允许动作。  
- **备选/异常流程**：无订单、阶段筛选无结果、访问他人订单、订单状态在读取期间发生变化。  
- **可验证结果**：仅返回本人参与的订单；不包含对方邮箱、手机号等账号隐私。  
- **追溯关系**：`REQ14 / UC14 / SYS-SEQ14 / COMP-TRADEDESK01 / OBJ-ORDER04 / UNIT-TC14 / INT-TC14 / E2E-TC14`

## UC15 学生提交举报并查看结果

- **需求编号**：REQ15  
- **参与者**：学生用户  
- **触发条件**：学生举报商品、留言或其他学生用户。  
- **前置条件**：已登录；举报对象属于允许类型；不能举报自己或重复举报。  
- **主成功流程**：提交举报理由，系统保存对象快照并创建 `OPEN` 举报；学生在“我的举报”查看进度和结果。  
- **备选/异常流程**：重复举报、超过 24 小时 20 条限制、对象不存在、举报自己、未登录。  
- **可验证结果**：举报进入管理员队列；学生只能查看自己的举报。  
- **追溯关系**：`REQ15 / UC15 / SYS-SEQ15 / COMP-GOVERNANCE01 / OBJ-REPORT01 / UNIT-TC15 / INT-TC15 / E2E-TC15`

## UC16 管理员治理举报对象

- **需求编号**：REQ16  
- **参与者**：管理员  
- **触发条件**：管理员处理举报队列中的 `OPEN` 记录。  
- **前置条件**：管理员 Session 有效且具备 ADMIN 权限。  
- **主成功流程**：核查举报快照，选择成立或驳回，填写说明；成立时执行匹配的下架、移除或禁用措施，并追加审计记录。  
- **备选/异常流程**：驳回举报、举报已被其他管理员处理、治理措施与对象类型不匹配、普通学生越权调用。  
- **可验证结果**：举报状态仅能从 `OPEN` 进入 `RESOLVED` 或 `DISMISSED`；同一举报只能最终处理一次。  
- **追溯关系**：`REQ16 / UC16 / SYS-SEQ16 / COMP-GOVERNANCE02 / OBJ-REPORT02 / UNIT-TC16 / INT-TC16 / E2E-TC16`

## UC17 管理员管理用户、商品和公开留言

- **需求编号**：REQ17  
- **参与者**：管理员  
- **触发条件**：管理员进入管理中心执行管理操作。  
- **前置条件**：管理员 Session 有效。  
- **主成功流程**：查看用户、商品和留言，禁用用户、管理商品审核状态、移除公开留言。  
- **备选/异常流程**：普通学生访问、资源不存在、交易状态与审核状态冲突、并发更新。  
- **可验证结果**：管理结果生效并记录必要状态；管理员操作不绕过交易状态机。  
- **追溯关系**：`REQ17 / UC17 / SYS-SEQ17 / COMP-ADMIN01 / OBJ-ADMIN01 / UNIT-TC17 / INT-TC17 / E2E-TC17`

## UC18 平台执行一次受保护业务操作

- **需求编号**：REQ18  
- **参与者**：学生用户、管理员、Session/CSRF 服务  
- **触发条件**：客户端提交任一写操作或受保护读取。  
- **前置条件**：请求携带有效 Session；写请求携带有效 CSRF。  
- **主成功流程**：服务端从当前 Session 获取操作者，校验角色和资源归属，执行对应领域服务。  
- **备选/异常流程**：未登录、CSRF 缺失、伪造用户 ID、越权访问、会话失效、管理员权限撤销。  
- **可验证结果**：非法请求被拒绝，合法请求成功；客户端不能决定操作者身份。  
- **追溯关系**：`REQ18 / UC18 / SYS-SEQ18 / COMP-SECURITY01 / OBJ-SECURITY01 / UNIT-TC18 / INT-TC18 / E2E-TC18`
