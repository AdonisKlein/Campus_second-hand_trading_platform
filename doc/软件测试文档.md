# 校园二手交易平台软件测试文档

## 1. 测试概述

本文档记录校园二手交易平台的测试范围、测试环境、自动化测试用例、手工测试用例、数据库测试和测试结论。测试对象包括 Spring Boot 后端接口、静态前端页面流程和 MySQL 数据库脚本。

## 6. 数据库测试

执行 `database/schema.sql` 后应创建：

```text
users
items
messages
trade_orders
email_verification
```

执行 `database/seed.sql` 后应插入：

- 管理员 `admin`。
- 普通用户 `alice`、`bob`。
- 演示商品：高等数学教材、宿舍小台灯、二手蓝牙耳机。

重点检查：

- `users.password_hash` 保存 BCrypt 散列。
- `users.role` 区分 `USER` 和 `ADMIN`。
- `users.status` 区分 `ACTIVE` 和 `DISABLED`。
- `items.status` 区分 `ON_SALE`、`SOLD`、`REMOVED`。
- 外键关系能约束商品、留言和订单关联的用户与商品。

## 7. 缺陷与处理

| 问题 | 处理方式 |
|---|---|
| 旧数据库结构和当前实体不一致 | 部署文档要求备份后重建数据库，并执行最新 `schema.sql`。 |
| SMTP 未配置导致验证码发送失败 | 部署文档说明需配置可用 SMTP 服务。 |
| 图片上传需求与实现不一致 | 文档明确当前版本使用图片地址，不支持文件上传。 |
| 权限模型较简单 | 文档明确为课程项目简化实现，后续可升级 Token 鉴权。 |

## 8. 测试结论

当前系统已覆盖校园二手交易平台的核心业务闭环：注册登录、密码重置、商品浏览与发布、留言沟通、订单创建与管理、个人资料维护和管理员管理。后端自动化测试用例全部通过，手工测试覆盖主要前端流程，满足课程项目验收要求。
