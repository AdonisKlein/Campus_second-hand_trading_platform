# 校园二手交易平台软件实现说明书

## 技术实现

系统由静态 Web 前端、Spring Boot 3.5 后端和 MySQL 8.4 组成。后端使用 Java 25、Spring Security、Spring Data JPA、Flyway 和 Spring Session JDBC；测试使用 JUnit 5、MockMvc、H2，并在 Docker 可用时使用 MySQL 8.4 Testcontainers。

前端使用原生 HTML、CSS、JavaScript。`frontend/assets/js/api.js` 集中处理 Session hydration、CSRF、登录前确认和统一错误反馈。前端不保存登录凭据，也不从 `localStorage`、请求体或查询参数推导身份。

## 模块实现

| 模块 | 主要实现 | 职责 |
|---|---|---|
| 身份与用户 | `security`、`user` | HttpOnly Session、CSRF、注册、登录、验证码、资料与密码重置。 |
| 商品与图片 | `item`、`media` | 商品发布、受控 JPG/PNG 上传、卖家管理、公开详情。 |
| 搜索 | `search` | 多关键词商品/用户搜索、区域、标签、价格和排序。 |
| 留言与私聊 | `message`、`chat` | 公开问答、买卖双方私聊、未读、屏蔽与举报。 |
| 交易 | `order` | 购买意向、预留、交接、完成和状态机。 |
| 内容治理 | `report`、`admin` | 举报、管理员处置和审计记录。 |

## 身份与安全

浏览器身份只由服务端 Session 确认。`CurrentActorService` 从当前会话取得用户；商品、订单、留言、私聊和管理员写操作均不接受客户端传入的用户身份字段。所有 Web 写请求经 `api.js` 携带 CSRF，后端继续校验资源归属和账号状态。

密码使用 BCrypt 保存。验证码保存 HMAC 摘要、用途、过期时间、尝试次数和消费状态。登录失败达到阈值会临时锁定账号；禁用、退出或账号版本变更会使会话失效。

## 商品、沟通与交易

商品由登录卖家发布，支持校园区域、交易标签、描述与一张平台受控图片。上传接口只接收 JPG/PNG，并限制体积、尺寸和卖家存储配额；图片会重新编码以清除元数据。公开详情只暴露安全卖家摘要，不返回邮箱或手机号。

公开留言仅用于商品问答。私聊会话只允许对应商品的买卖双方读取和发送；管理员不能读取学生私聊正文。消息使用单调 sequence 和游标分页，前端当前每 8 秒轮询未读及会话更新。

买家提交的是非独占购买意向，商品仍保持 `ON_SALE`。卖家接受一条意向后，订单进入 `WAITING_HANDOVER`、商品进入 `RESERVED`，其他待回应意向关闭。买家确认线下交接后，订单进入 `COMPLETED`，商品才变为 `SOLD`。取消或预留过期按 `TradingService` 的状态机处理，Controller 和前端不自行修改交易状态。

## 数据、部署与验证

Flyway 从空数据库依次执行 `V1` 至 `V5` 迁移；Hibernate 只做映射校验，不自动建表。Docker 部署由 `deploy/docker-compose.yml` 提供 MySQL、后端和 Nginx，开发可额外叠加 Mailpit 接收测试验证码。

自动化测试覆盖会话与权限反向用例、验证码、商品与图片、搜索、举报、私聊和交易状态机。真实 MySQL 测试验证 Flyway 空库迁移与 Hibernate 映射；前端 Node 测试验证会话竞态、认证跳转和页面结构契约。

## 当前边界

- Web 使用服务端 Session；Windows 和移动原生端令牌适配尚未实现。
- 当前支持单张商品图片和文本私聊；多图、图片消息、结构化议价及 WebSocket/SSE 尚未实现。
- 不提供在线支付、物流配送和评价体系。
