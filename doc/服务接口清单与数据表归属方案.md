# 服务接口清单与数据表归属方案

> 文档状态：当前实现基线
>
> 核对依据：后端 Controller、领域 interface、Flyway `V1`～`V6` 迁移和 Postman 契约
>
> 架构形态：模块化单体。这里的“服务”指业务模块及其稳定调用 interface，不代表已拆分为独立微服务。

## 1. 归属原则

1. 每个业务表只有一个模块 owner；其他模块只能通过 owner 提供的 interface 读取或请求变更。
2. Controller 只负责 HTTP 参数、Session/角色取得、CSRF 由安全配置统一校验和响应包装；业务规则由领域服务执行。
3. 所有需要当前用户的写操作都从 `CurrentActorService` 取得身份，不接受请求体中的 `userId`、`sellerId` 或 `adminId` 作为授权依据。
4. `trade_orders` 的状态修改只能经 `TradingService`；商品、留言、举报和管理员操作必须检查资源归属或角色。
5. 外键表示数据关系，不表示跨模块拥有写权限。订单、举报和私聊中的快照字段由各自 owner 管理。
6. `SPRING_SESSION` 系列表由 Spring Session JDBC adapter 管理，业务模块不得直接操作。

## 2. HTTP 服务接口清单

| 编号 | 模块 | HTTP 入口 | 主要操作 | 调用的核心服务/interface | 访问范围 |
| --- | --- | --- | --- | --- | --- |
| API-01 | `user` | `/api/auth` | CSRF、注册验证码、重置验证码、注册、登录、退出、重置密码 | `VerificationService`、`RegistrationService`、`EmailService` | 验证码/注册公开；登录态操作按 Session |
| API-02 | `user` | `/api/users` | 查询和修改当前用户资料 | `CurrentActorService`、用户服务 | 已登录本人 |
| API-03 | `search` | `/api/search` | 商品/用户多关键词搜索、筛选、排序、分页 | `CampusSearch.search` | 公开；用户结果为安全投影 |
| API-04 | `item` | `/api/items` | 商品公开列表、详情、我的发布、发布、编辑、卖家动作 | `ProductDetail.show`、`SellerInventory` | 浏览公开；写入仅卖家本人 |
| API-05 | `media` | `/api/media/product-images` | 商品图片上传和受控读取 | `ProductImages.store/load` | 上传需登录；读取受控路径 |
| API-06 | `message` | `/api/messages` | 公开留言查询、发布、修改、删除 | 商品可见性规则、留言服务 | 查询随商品可见性；修改/删除仅本人 |
| API-07 | `chat` | `/api/chat` | 创建会话、订单会话、会话列表、历史、发送、已读、屏蔽、未读数 | `DirectChat` | 仅真实买卖双方；管理员无私聊正文特权 |
| API-08 | `order` | `/api/orders` | 订单列表、交易工作台、购买意向、交易动作 | `TradingService`、`TradeDesk.browse` | 仅交易参与者；写操作走状态机 |
| API-09 | `report` | `/api/reports` | 提交举报、我的举报、收到的治理结果 | `ContentGovernance` | 学生本人；禁止自报和重复举报 |
| API-10 | `report` | `/api/admin/reports` | 举报队列和治理决定 | `ContentGovernance` | 仅 ADMIN Session |
| API-11 | `admin` | `/api/admin` | 用户状态、留言、商品及后台统计管理 | 管理员服务、商品/留言 owner 规则 | 仅 ADMIN Session |

## 3. 核心业务 interface

| Interface | Owner | 稳定职责 | 禁止事项 |
| --- | --- | --- | --- |
| `CurrentActorService` | `security` | 从有效 Session 得到当前用户、状态和角色 | 不从请求体或 localStorage 推导身份 |
| `CampusSearch` | `search` | 商品/用户搜索及安全公开投影 | 暴露邮箱、手机号等登录资料 |
| `SellerInventory` | `item` | 发布、本人列表、编辑、卖家下架/重新上架 | 修改他人商品或已预留/售出商品 |
| `ProductDetail` | `item` | 商品详情、卖家摘要、当前用户动作 | 在前端复制交易授权规则 |
| `ProductImages` | `media` | 图片验证、标准化存储和受控读取 | 接受任意路径或跨 owner 文件 |
| `DirectChat` | `chat` | 会话唯一性、参与者授权、消息顺序、已读和屏蔽 | 管理员读取学生私聊正文 |
| `TradeDesk` | `order` | 买卖视角工作台、阶段统计、时间线和允许动作 | 直接写交易状态 |
| `TradingService` | `order` | 购买意向、接受/拒绝/取消/完成/过期状态变更 | Controller 或前端自行推进状态 |
| `ContentGovernance` | `report` | 举报提交、查询、管理员决定和追加审计 | 不匹配治理措施与举报对象 |
| `EmailService` | `common` | 只负责发送验证码邮件 | 理解验证码业务状态或保存明文验证码 |

## 4. 数据表归属

| 表 | Flyway | Owner 模块 | 数据职责 | 主要访问边界 |
| --- | --- | --- | --- | --- |
| `users` | V1/V2/V6 | `user` | 登录资料、角色、账号状态、区域、信用和活动时间 | `user` 写；其他模块按最小字段读取 |
| `email_verification` | V1 | `user` | 验证码 challenge、用途、过期和消费状态 | 仅验证码服务 |
| `items` | V1/V2/V5 | `item` | 商品内容、卖家、交易状态、审核状态和版本 | `item` 写；`order/report/admin` 通过规则请求变更 |
| `item_tags` | V2 | `item` | 商品标签集合 | 随商品发布/编辑维护 |
| `messages` | V1 | `message` | 商品公开留言及发送/接收关系 | 商品可见性过滤；本人维护；管理员治理可移除 |
| `trade_orders` | V1/V5 | `order` | 购买意向/预留订单、快照、状态、过期和关闭原因 | 仅 `TradingService` 写；参与者读取 |
| `content_reports` | V3/V6 | `report` | 举报对象快照、状态、治理结果、证据和被举报方回执 | `ContentGovernance` 写；学生查本人，管理员查队列 |
| `report_actions` | V3 | `report` | 管理员处理历史追加审计 | 只追加，不更新历史；仅治理服务写 |
| `chat_conversations` | V4 | `chat` | 私聊参与者、商品快照、未读游标和会话摘要 | 仅参与者读取；`DirectChat` 写 |
| `chat_messages` | V4 | `chat` | 私聊正文和单调 sequence | 仅参与者读取；发送者由 Session 推导 |
| `chat_blocks` | V4 | `chat` | 屏蔽关系 | 用户只能维护自己的屏蔽关系 |
| `SPRING_SESSION` | V1/adapter | `security` adapter | Session 主记录和过期信息 | Spring Session JDBC 管理 |
| `SPRING_SESSION_ATTRIBUTES` | V1/adapter | `security` adapter | Session 属性 | Spring Session JDBC 管理 |

图片二进制不进入业务数据库，由 `media` 模块的文件系统 adapter 持久化；`items.image_url` 只保存受控资源引用。邮件正文也不落库。数据库结构由 Flyway 管理，Hibernate 仅执行 `validate`。

## 5. 跨模块关系与写入边界

| 协作关系 | 允许方式 | 关键约束 |
| --- | --- | --- |
| `item` ↔ `order` | 订单读取商品并请求交易状态联动 | 商品预留/售出只能由交易服务按状态机完成 |
| `item` ↔ `message` | 留言按商品公开可见性读取 | 下架、移除或禁用后不得旁路读取/写入 |
| `item` ↔ `chat` | 会话保存商品快照并读取当前交易上下文 | 会话历史保留，发送权限仍由参与者和屏蔽规则决定 |
| `report` ↔ 被举报对象 | 提交时读取并保存简要快照 | 决定时只能执行与对象类型匹配的治理措施 |
| `admin` ↔ 业务模块 | 通过模块公开操作或明确治理 interface | ADMIN 角色不等于可绕过交易状态机或私聊隐私 |

## 6. 变更同步要求

新增或修改 HTTP 入口、核心 interface、表、状态或权限时，必须同时更新本清单、`doc/postman_collection.json`、相关测试、`docs/ai/PROJECT_CONTEXT.md` 和 `docs/ai/WORKLOG.md`。若只是内部实现替换且 interface 与契约不变，只需更新实现说明和测试证据。
